Assets for the WordPress.org plugin directory. These are deployed to the SVN
`assets/` folder by the 10up deploy action.

Expected files:

- `banner-772x250.png` (or .jpg) — Plugin banner
- `banner-1544x500.png` (or .jpg) — Hi-DPI plugin banner
- `icon-128x128.png` (or .jpg) — Plugin icon
- `icon-256x256.png` (or .jpg) — Hi-DPI plugin icon
- `screenshot-1.png` (or .jpg) — Screenshots referenced in readme.txt
